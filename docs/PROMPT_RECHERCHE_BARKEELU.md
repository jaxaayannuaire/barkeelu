# 3. MODÈLE ÉCONOMIQUE À ANALYSER

Hypothèse actuelle de Barkeelu :

### Frais plateforme

**4 % par transaction**, supportés par le donateur.

### Frais de transfert

**1 % pour l'envoi Wave vers le promoteur/bénéficiaire.**

Total standard :

**5 %**

Exemple :

```text
Don brut                  100 000 FCFA
Frais Barkeelu 4 %          4 000
Transfert Wave 1 %          1 000
------------------------------------
Solde campagne             95 000
```

### Rémunération promoteur

Hypothèse :

**1 à 1,5 % de la somme recueillie après les frais.**

Exemple à 1,5 % :

```text
95 000 × 1,5 % = 1 425 FCFA
```

Net après commission promoteur :

```text
93 575 FCFA
```

## IMPORTANT

Ne considère pas ce modèle comme définitivement validé.
